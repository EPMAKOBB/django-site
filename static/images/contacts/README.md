# QR-коды контактов на главной

Заменяемые изображения:

- `telegram.png` — `https://t.me/EPMAKO`
- `whatsapp.png` — `https://wa.me/79296435092`

Чтобы использовать свои QR-коды, замените эти PNG-файлы, сохранив имена.
Рекомендуемый размер — от 330×330 пикселей. Сохраните белое поле вокруг
кода; картинка не должна быть обрезана вплотную к чёрным модулям.
На странице коды раскрываются по нажатию «Показать QR-коды».

Если изменится контакт, обновите и изображение, и соответствующие ссылки
в `templates/home.html`. Изменение изображения автоматически меняет версию
URL через `versioned_static`. Для публикации файлы входят в обычный деплой
статических ресурсов проекта; загрузка через Django admin не требуется.
