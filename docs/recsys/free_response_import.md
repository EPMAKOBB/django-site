# Импорт заданий с развёрнутым ответом

Команда `import_free_response_tasks` сохраняет задачи как черновики. Эталон —
строка с ответом, при необходимости с решением и критериями. Массив из 17 клеток
для второй части не подходит. Markdown и формулы поддерживаются в условии.

Пример файла JSON:

```json
[
  {
    "type_number": 13,
    "slug": "13-01-fipi-math-ege-2027-demo",
    "title": "Демоверсия ЕГЭ 2027. Задание 13. Пример 1",
    "description": "а) Условие первого пункта.\n\nб) Условие второго пункта.",
    "correct_answer": "а) Эталон первого пункта.\nб) Эталон второго пункта.\n\nКритерии оценивания из PDF."
  }
]
```

Проверка на базе, выбранной настройками Django, без записи:

```text
python manage.py import_free_response_tasks --path tasks.json --exam-version-id 12 --source-variant-id 132
```

Для записи добавить `--apply`. Команда проверяет все записи перед сохранением;
ошибка отменяет весь пакет. Повторный импорт существующих задач отклоняется.
Источник определяется по варианту, предмет — по экзамену, баллы — по типу.
Схема должна быть активной, с `manual_check: true`, `ui_hint: textarea` и одним
текстовым полем. Для задачи и назначения явно задаются `manual_scaled`, схема
ответа и максимальный балл, даже если тип ошибочно настроен на `binary`.

Проверить настройки свободного ответа в неопубликованном экзамене:

```text
python manage.py fix_free_response_scoring --exam-version-id 12
```

С `--apply` команда исправляет схемы оценивания типов. Это требует права UPDATE
на таблицу типов; учётной записи импортёра такое право не требуется.
Опубликованную конфигурацию команда менять не позволяет.

Ответ, ожидающий ручной проверки, не имеет баллов. Он не должен отображаться как
неправильный или уменьшать показатели освоения. Выставление оценки преподавателем
— отдельный процесс; эта команда только загружает условия и эталоны.
