# Стандартизация оформления: 30 октября 2026

Ориентир — согласованные страницы экзамена и тренировки. Общие компоненты
перенесены в `site-foundation.css`; специальные раскладки сохранены в стилях разделов.

## Изменения

- Единые размеры заголовков, отступы и скругления панелей; нейтральные рамки карточек.
- Общие поля с затемнённым фоном, видимым фокусом и состоянием ошибки;
  единая адаптивная сетка форм, оформление файловых полей и множественного выбора.
- Исправлены отсутствовавшие модификаторы кнопок в курсе; кнопки заявки,
  парсера и карты вариантов используют общие стили. Добавлен настоящий `.btn-link`.
- Статусы используют семантические цвета текущей темы, без фиксированных
  зелёных/розовых/жёлтых цветов; ошибки и предупреждения визуально различаются.
- Прогресс курса и назначенных работ использует общую дорожку и стартовую отметку.
  Числа и код сохраняют отдельную типографику.
- Убраны лишние вложенные рамки и отступы в мобильном модуле курса, списке задач
  и просмотре варианта. Широкий контент прокручивается внутри условия.
- Заголовки настроек, курсов и инструментов преподавателя приведены к общей иерархии.
  Заголовок настроек перенесён в начало страницы.
- Все локальные CSS подключаются с хешем содержимого. Удалены дубли общих полей
  и сеток из стилей загрузки заданий; её вспомогательные стили ограничены разделом.

| Область | Экраны и состояния |
|---|---|
| Гостевые | Главная, вход, регистрация, заявка и её подтверждение, материалы |
| Учебные | Экзамен, тип заданий, банк задач, страница варианта |
| Кабинет | Мои работы, настройки, назначенная работа, история результатов |
| Курсы | Заполненный курс с графом, теория с кодом/таблицей, практическое задание |
| Решатель | Тренировка и экзамен; отдельно 10/100 задач и таблицы ответов 2×2/10×2 |
| Расписание | Календарь с занятием, часовой пояс, создание урока и серии |
| Преподаватель | Учительская, ученики, классы, карточка ученика, назначение варианта |
| Контент | Методист, журнал системы, загрузка/редактирование задач, карта и сборщик вариантов, управление парсером |

35 экранов и состояний проверены в Chromium в обеих темах при ширинах
375, 768 и 1440 px. Для экзамена и компактного решателя дополнительно проверены
320 px. Проверки выполняются на временных пользователях, учебной работе,
курсе и занятии в локальной базе; созданные записи удаляются после прогона.

Проверены расчёт цены при выборе предметов, добавление/удаление строк умений,
переключение календаря, фокус полей, подсказки режимов, подбор задач,
навигация решателя и его таблицы ответов. Финальные прогоны — без ошибок JavaScript
и горизонтального переполнения страницы; широкие таблицы сохраняют внутреннюю прокрутку.

287 тестов для recsys, accounts, courses, lessons, students, fractalschool и subjects,
а также 3 теста заявок прошли. Все 175 HTML-шаблонов компилируются;
`manage.py check` и `git diff --check` проходят.

Снимки и отчёты: `.local/design-standard-qa`, `.local/compact-solver-qa`,
`.local/exam-modes-qa`. Полный журнал тестов — `.local/design-standard-tests.log`.
Локальная копия media неполна: полнота исходных изображений в эти проверки не входит.
Рабочие данные пользователей, расчёты прогресса и серверные сценарии этой итерацией
не изменялись. Коммиты, публикация и деплой не выполнялись.
