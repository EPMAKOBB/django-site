# Как записывать формулы в Markdown для сайта

На сайте текст задания можно писать в Markdown. Формулы рендерятся через KaTeX, поэтому для них нужно использовать специальные разделители.

## Строчные формулы

Строчная формула находится внутри обычного предложения.

Рекомендуемый вариант:

```md
Расстояние между точками \(A(x_1, y_1)\) и \(B(x_2, y_2)\) вычисляется по формуле ниже.
```

Можно также использовать одинарные доллары:

```md
Расстояние между точками $A(x_1, y_1)$ и $B(x_2, y_2)$ вычисляется по формуле ниже.
```

## Блочные формулы

Блочная формула выводится отдельной строкой.

Рекомендуемый вариант:

```md
\[
d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]
```

Можно также использовать двойные доллары:

```md
$$
d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$
```

## Пример текста задания

```md
Будем называть центром кластера точку этого кластера, сумма расстояний от которой до всех остальных точек кластера минимальна. Для каждого кластера гарантируется единственность его центра.

Расстояние между двумя точками на плоскости \(A(x_1, y_1)\) и \(B(x_2, y_2)\) вычисляется по формуле:

\[
d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]
```

## Частые ошибки

Не используйте обычные квадратные скобки для формул:

```md
[
d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
]
```

Такой текст будет показан как обычный текст, потому что `[` и `]` не являются разделителями формул.

Правильно:

```md
\[
d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]
```

## Если текст хранится в JSON

Если Markdown записывается внутри JSON-строки, обратные слеши нужно экранировать:

```json
{
  "description": "Расстояние между точками \\(A(x_1, y_1)\\) и \\(B(x_2, y_2)\\):\n\n\\[\nd(A, B) = \\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\n\\]"
}
```

Если текст вводится напрямую в админке или форме сайта, экранировать слеши не нужно.

## Мини-шпаргалка

```md
\(x^2 + y^2 = r^2\)     # формула внутри строки

\[
x^2 + y^2 = r^2
\]                      # формула отдельным блоком
```
